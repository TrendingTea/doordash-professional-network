# Hypothetical McDonald's Pilot

McDonald's is used as a hypothetical high-volume case-study merchant only.

## Pilot design
- 50 restaurant locations
- 8 weeks
- structured post-pickup feedback
- voluntary Dasher profiles
- manager mobile workflow
- control vs pilot comparison where feasible

## Primary metrics
- pickup dwell time
- merchant feedback completion rate
- merchant complaint rate
- Dasher block rate
- order handling incidents
- professional recognition rate
- Dasher profile activation
- career-interest engagement

The included `seed.py` creates 50 synthetic McDonald's locations and 1,000 synthetic deliveries.
