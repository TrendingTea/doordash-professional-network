# Privacy and Safeguards
- Dasher professional profiles are voluntary.
- Private phone numbers, addresses, and personal email addresses are not exposed.
- Feedback questions focus on observable pickup behavior.
- Protected characteristics are never solicited.
- Negative feedback should not create immediate punitive consequences.
- Minimum sample sizes should apply before aggregate ratings are displayed.
- Dashers need dispute/correction mechanisms.
- Fraud/anomaly detection should identify coordinated or abusive rating behavior.
